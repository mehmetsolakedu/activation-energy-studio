# Example data

`synthetic_kas_150.csv` is a deterministic, non-experimental fixture. Its
fixed-conversion temperatures were constructed so that KAS recovers exactly
150 kJ mol⁻¹ at alpha 0.10–0.90 for heating rates 5, 10, 20, and 40 K min⁻¹.

It exists to verify the complete file-import → normalization → calculation →
reporting path. It must never be presented as measured material data.
