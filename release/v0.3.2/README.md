# Activation Energy Studio v0.3.2 Research Preview

Open `index.html` for the download page, or open
`Activation-Energy-Studio-v0.3.2.html` directly in a current desktop browser.
The application is a self-contained offline HTML file. It requires no
installer, server, account, telemetry connection, or Parallels.

## First five minutes

1. Choose one of the three licensed real examples, or upload CSV, TSV, TXT, or
   XLSX files from one sample and physical reaction stage.
2. Inspect the detected encoding, delimiter, header, worksheet, mapping, units,
   TG/DTG preview, stage bounds, `m0`/`mf` anchors, and `alpha` definition.
3. Explicitly confirm the interpretation. Instrument profiles and stage
   suggestions are advisory and are never silently accepted.
4. Run the eligible methods, read the four-state scientific disposition and
   reportable `alpha` range, then retain PDF, CSV, and reproducible JSON
   together.

See `QUICK_START.md` for detailed instructions.

## v0.3.2 remediation boundary

This release corrects fail-closed time-series handling, raw-series Friedman
derivative placement, stale asynchronous state commits, revision-bound export,
duplicate-filename source identity, and licensed-example export provenance. It
does not broaden the validated methods, datasets, platforms, or scientific
claims.

## Integrity and support

- Verify package bytes with `SHA256SUMS.v0.3.2.txt`.
- Inspect the exact package inventory in `MANIFEST.v0.3.2.json`.
- Validate reproducible JSON against `project-report.schema.json`.
- Cite the software through `CITATION.cff` and every example through
  `THIRD_PARTY_NOTICES.md`.
- Report a reproducible issue by following `SUPPORT.md`.

This is a Research Preview, not certified instrument software. Outputs are
apparent activation energies conditional on sample, atmosphere, physical
stage, preprocessing, method, and selected conversion range.
