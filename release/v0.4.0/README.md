# Activation Energy Studio v0.4.0 audit candidate

This directory is a complete, hash-bound **audit candidate package**. It is not
an externally published release, journal revision, deployment, or Zenodo
deposit. External publication remains blocked until the audit decision is
positive and Mehmet Solak gives explicit approval. The historical v0.3.2
artifact remains immutable.

Open `Activation-Energy-Studio-v0.4.0.html` in a current browser to run the
single-file application locally. No installer or server is required. Read
`QUICK_START.md` before importing research data.

Package contents include:

- the self-contained application HTML and English landing page;
- the v1.1 scientific correction contract, report JSON Schema, and import
  templates;
- sole-author citation metadata, the MIT project license, dataset notices,
  production dependency notices, a CycloneDX production SBOM, and bundled
  third-party license texts;
- release-candidate notes, support instructions, a deterministic manifest, and
  SHA-256 checksums.

Verify every file against `SHA256SUMS.v0.4.0.txt`, then verify the manifest with
`npm run verify:release-manifest:v0.4.0` from the reviewed source tree. Package
integrity proves only byte identity. It does not by itself establish scientific
validity, universal instrument suitability, human usability, or publication
approval.
