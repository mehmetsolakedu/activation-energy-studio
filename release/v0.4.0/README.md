# Activation Energy Studio v0.4.0 Research Preview

This directory is the complete, hash-bound **v0.4.0 Research Preview release
package**, approved for public distribution by Mehmet Solak on 2026-09-12. The
canonical repository is
<https://github.com/mehmetsolakedu/activation-energy-studio>; the canonical web
entry point is <https://mehmetsolak.cc/activation-energy-studio/>. Journal and
Zenodo records have their own versioned workflows and are not changed merely
by distributing this package. The historical v0.3.2 artifact remains
immutable and separately identifiable.

This release was promoted from frozen candidate commit
`7ea6575342c822eae609ba3d32a785dcb5a94b6e` after the audit verdict
**CONDITIONAL PASS — SAFE RESEARCH PREVIEW WITH LISTED LIMITATIONS**. Promotion
changed only release-state interface wording, documentation, citation and
package metadata, and their tests. Scientific and calculation code is
unchanged from the frozen candidate.

Open `Activation-Energy-Studio-v0.4.0.html` in a current browser to run the
single-file application locally. No installer or server is required. Read
`QUICK_START.md` before importing research data.

Package contents include:

- the self-contained application HTML and English landing page;
- the v1.1 scientific correction contract, report JSON Schema, and import
  templates;
- sole-author citation metadata, the MIT project license, dataset notices,
  production dependency notices, a CycloneDX production SBOM, and bundled
  third-party license texts;
- release notes, support instructions, a deterministic manifest, and
  SHA-256 checksums.

Verify every file against `SHA256SUMS.v0.4.0.txt`, then verify the manifest with
`npm run verify:release-manifest:v0.4.0` from the reviewed source tree. Package
integrity proves only byte identity. It does not by itself establish universal
scientific validity, instrument suitability, human usability, deployment at a
particular URL, journal acceptance, or regulatory fitness.
