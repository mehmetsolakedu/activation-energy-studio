# Support and bug reports

Send a reproducible bug report to the maintainer:

<mailto:mehmetsolak@siirt.edu.tr?subject=Activation%20Energy%20Studio%20v0.3%20bug%20report>

Use the subject prefix `[SCIENTIFIC]`, `[ACCESSIBILITY]`, `[I18N]`, or
`[OFFLINE]` when one applies. The message body should contain the checklist
below.

Do not upload confidential, proprietary, embargoed, or personally identifying
experimental data. A minimal reproducible report should include:

1. Activation Energy Studio version and the SHA-256 of the HTML artifact.
2. Operating system, browser name/version, language, and simple/expert mode.
3. Import format, selected sheet/header/layout, units, heating rates, stage,
   alpha range, and method.
4. The exact visible diagnostic code and message.
5. Expected versus observed behavior and reproducible steps.
6. A redacted minimal input or one of the bundled example/template names.
7. Exported JSON when it can be shared safely; remove sensitive project and
   sample metadata first.

For a suspected scientific error, prefix the message subject with
`[SCIENTIFIC]`. For an accessibility or translation problem, use
`[ACCESSIBILITY]` or `[I18N]`. For an offline/network problem, use
`[OFFLINE]`.

Security-sensitive reports should begin with `[SECURITY]` and omit exploit
details from the first message; request a private coordination channel.

This research preview does not provide emergency, clinical, regulatory, or
production-control support.
