# v0.3.2 Usability Evidence Return Checklist

Return a working-copy directory containing:

- [ ] completed `study-input.json`;
- [ ] five retained participant JSON records, exactly P01–P05;
- [ ] five separate screen recordings and five separate audio recordings;
- [ ] five happy-path PDF exports;
- [ ] any optional screenshots/renders referenced by participant records;
- [ ] eight distinct W1–W4 UI/PDF warning evidence artifacts;
- [ ] ten deterministic blind second-rater records;
- [ ] excluded/incomplete session log, including zero-entry log if none;
- [ ] coordinator signed-record reference;
- [ ] recorder-produced `usability-evidence-record.json`;
- [ ] recorder `--check` output;
- [ ] independent human evidence audit and signed reference; and
- [ ] SHA-256 inventory of every returned artifact.

Do not return identity data or signed consent forms in this de-identified
evidence directory. Return only pseudonymous consent references. Do not modify
or replace package locks to make an observation pass.
