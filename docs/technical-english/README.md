# Technical English Documentation Index

the immutable v0.2 governance and validation documents listed below. The
original root files remain byte-for-byte unchanged because
`release/MANIFEST.v0.2.0.json` binds their exact paths, sizes, and SHA-256
digests as historical evidence.

retroactively modify the v0.2 evidence record; the byte-bound source remains
authoritative for that historical record. The usability edition additionally
contains an explicitly labelled v0.3.1 English workflow, while preserving its
historical-source boundary.
